# FULL LOGISTICS

Современный адаптивный landing page для фулфилмент- и логистической компании. Проект работает без сборщика и сторонних UI-фреймворков.

## Структура

- `index.html` — вся семантическая разметка и тексты страницы.
- `css/style.css` — дизайн, адаптивные состояния и анимации.
- `js/main.js` — меню, вкладки FBS/FBO, калькулятор, FAQ, modal, формы и галерея.
- `assets/images/` — фотографии и графика секций.
- `assets/logo/` — логотип.
- `assets/icons/` — favicon и дополнительные иконки.

## Запуск

Откройте `index.html` двойным кликом — сайт не требует сборки. Для локального сервера можно выполнить в папке проекта:

```bash
python3 -m http.server 8000
```

После этого откройте `http://localhost:8000`.

## Где менять данные

- Тексты всех секций: `index.html`.
- Цены: строки блока `#pricing` в `index.html`; цены калькулятора также указаны в атрибутах `data-price` блока `#calculator`.
- Контакты: найдите в `index.html` телефон `+996 226 199 898`, адрес и ссылки `wa.me`.
- Изображения: замените WebP-файлы в `assets/images/`, сохранив имена файлов, либо измените пути в HTML/CSS.
- Логику отправки формы: функция `submitLead()` в `js/main.js`. Сейчас она безопасно имитирует успешную отправку без сетевого запроса.
